# Cursor (macOS)

## Restore

```bash
mkdir -p ~/Library/Application\ Support/Cursor/User
cp ~/workflow-helper/mac/cursor/keybindings.json ~/Library/Application\ Support/Cursor/User/keybindings.json
```

## Keys

| Key | Action |
|---|---|
| Ctrl+Cmd+1 / Ctrl+Cmd+E / Cmd+K Cmd+E | editor 1 |
| Ctrl+Cmd+2 | editor 2 |
| Ctrl+Cmd+3 / Ctrl+Cmd+` | terminal (focus) |
| Ctrl+` | terminal (toggle panel) |
| Opt+Cmd+Up / Down | previous / next terminal group |
| Opt+Cmd+Left / Right | previous / next split pane |
| Cmd+\ | split terminal (when focused) |
| Opt+Cmd+Backspace | kill terminal (when focused) |
| Opt+Left / Right | word-wise movement in the shell |
| Cmd+I | chat panel (toggle) |
| Cmd+L | chat (focus / add) |
| Ctrl+Cmd+L | add files to composer |
| Ctrl+Shift+Q | collapse explorer folders |
